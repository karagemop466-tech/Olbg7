# Official / primary sources used (2026-10-26 pass)

Every priced row on the site links to its OLBG event page **and** to one of the official sources below.
"Official" = competition/league/governing-body site. Where only a reputable results database exists
(e.g. snooker.org for the full WST draw), that is stated on the row and in the verification log.
