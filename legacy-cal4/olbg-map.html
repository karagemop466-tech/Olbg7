How OLBG is structured, and what we could read from it

The site is confusing because one sport page mixes fixtures, outrights, blogs and adverts. This page is the map: the URL grammar, the id behind each sport, the markets each listing actually prints, and how much of each sport we could price today.

The URL grammar

sport root        https://www.olbg.com/betting-tips/{Sport}/{sport_id}
competition       https://www.olbg.com/betting-tips/{Sport}/{Group}/{Competition}/{sport_id}
competition list  https://www.olbg.com/betting-tips/{Sport}/{Group}/{Competition}/All_Events/{sport_id}
sport list        https://www.olbg.com/betting-tips/{Sport}/All_{Sport}/All_Events/{sport_id}
single event      https://www.olbg.com/betting-tips/{Sport}/{Group}/{Competition}/{Event_Slug}/{sport_id}?event_id={id}
  • The trailing number is the sport id and is stable across every page for that sport. A wrong id returns a hard 404 (tennis is 3; 6 returns 404).
  • ?event_id= is required. Two different events can share a slug.
  • The event slug is the event name with spaces replaced by underscores; @ is kept for US sports.
  • Where the listing is not a competition, the group segment is All_{Sport} and the competition segment is All_Events.
  • Gaelic sports are two separate OLBG sports: Gaelic Football 25 and Hurling 26.

What OLBG does not print

  • Odds. Prices are rendered client-side and did not appear in any retrieved page, so every price on this site is ours and no bookmaker comparison is claimed.
  • Timezones. Start labels are printed without one, so they are copied verbatim and the conflicts with official times are listed on Flagged for review.
  • Field sizes for outrights. The number of runners is not printed, so outright prices use a stated 1-in-8 prior and are labelled as estimates.
  • Snooker and greyhounds today. Both listings return “No tips found”, which is a statement about the page rather than about the sport.
