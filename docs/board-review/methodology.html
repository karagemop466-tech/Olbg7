How every line in this project is built

Originated prices, in the open. No bookmaker price is copied and no number is invented.

1. What OLBG actually publishes

OLBG lists events, the most-tipped selection per market, a tip count and a percentage. Reverse-engineering the site (see Sources) shows event pages expose the full market ladder — for example, the tennis page for Wawrinka v Lehecka lists Win Match, Set Betting, 1st Set Winner, Games Won and Total Games — but the bookmaker price behind each selection is not exposed to a logged-out request. So every price on this site is originated here, which is what the brief asked for.

2. Tier A — data-backed lines

A line is Tier A only when both teams appear in an official competition table captured on the day. The method is deliberately small and checkable:

StepFormulaSource of the input
Team strength(goals or points for − against) ÷ games playedOfficial standings table
Expected margin(strength home + home edge) − strength awayHome edge is a stated constant per sport
Win probability1 ÷ (1 + e−margin ÷ σ)σ is a stated spread constant per sport
Price(1 ÷ probability) × 1.05 margin5% two-way margin, then converted to American odds

Handicap lines come from the same expected margin, rounded to the sport's increment. Totals come from each side's verified scoring rate against the opponent's concession rate. Constants used: handball σ 9.0, home edge 0.6 goals; basketball σ 15.0, home edge 2.5 points; ice hockey σ 2.6, home edge 0.25 goals. These are stated so you can reproduce or challenge every number in scripts/build_data.py.

3. Tier B — reference lines

Most of the board has no official table in our verified set (tennis, volleyball, cricket, rugby, golf, darts, the dogs). Those events still get a price, but it is built only from the OLBG tip share, shrunk toward 50/50 by sample size (weight = n ÷ (n + 10)), with the same 5% margin. A Tier B line is a reference, not evidence: it is labelled on every table row and it is why Tier B predictions are graded Medium or Low, never High.

4. Confidence and the odds window

GradeRuleWhat it means
HIGHimplied probability ≥ 65%Our price says the selection should win about two times in three
MEDIUM55% – 65%Lean, not a conviction
LOWbelow 55%Noted for completeness; small stakes only

The brief asked for picks above 70% and no shorter than −250. Those two conditions overlap only between 70.0% and 71.4%, because −250 is itself 71.4%. We therefore apply the −250 to +10000 price window to every selection (shown as a tag on each prediction) and grade confidence on probability separately. One pick in this project lands in the literal 70–71.4% band; it is named on Flagged for Review.

5. Markets investigated per sport

Market ladders were read from OLBG's own documentation and event pages, then priced where an input existed: handball Money Line, handicap and total; basketball Money Line, pointspread, total; ice hockey Money Line, puck line, game totals; tennis Win Match, Set Betting, 1st Set, Games handicap, Total Games; volleyball win match and set markets; cricket win match, top batter, man of the match; rugby union match and handicap; golf outright, first round leader and top-region markets; F1 qualifying, race win, podium, top 6, fastest lap. Where a market had no verified input it is listed as un-priced rather than filled in.
